# iOS・Apple Watch・Live Activityの画面構成

本人だけが使う前提で、受信した電文の解析結果をすべて画面で確認できるようにしています。要点を先に表示し、詳細は折りたたみやシートで開きます。値はVPSが解析した項目だけを使い、表示のために推測や補完はしません。

## 共通の表示規則

- 震度は気象庁の配色（色覚に配慮した版）のバッジで表示します。範囲（3〜4）、以上、未入電は記載どおりに表示します。
- 時刻は端末のタイムゾーンで、24時間表記・秒まで表示します。
- 1つの値には、出所の電文（電文コードと名称）と発表時刻を併記します。種類の違う電文の値を混ぜて表示しません。
- EEWだけ「第○報」を表示します。それ以外は発表区分（発表・訂正・遅延・取消）で表示します。
- 警報（VXSE43）のM・深さは表示しません。同じ地震の予報の値は「予報（参考）」として別に表示します。

## iPhone

タブは「概況」「地震」「津波」「関連情報」「設定」の5つです。

**概況**
- 受信状態：DMDATAとの接続、最終フレームと最終電文の受信時刻、再接続と拒否の回数、DB・APNs、同期とserver_sequence
- 発表中：継続中のEEWと津波警報・注意報・予報
- 24時間・7日間・30日間の地震の件数と最大震度（観測値だけ。地震ごとの値は一覧と同じ規則で選びます）
- 最近の地震5件と、最新の津波・関連情報

**一覧**
- 地震：震度バッジ、震源、発生時刻、M・深さ、情報の種類と発表区分、継続中・取消・最終・仮定・低精度の印
  - 震度バッジは、その地震で受信したすべての電文から選びます。震源・震度情報（なければ震度速報、さらになければ長周期地震動に関する観測情報）の最大震度を使い、観測値がなければEEWの予想最大震度を「予想」付きで表示します。詳細画面の見出しと同じ規則です
  - 一覧の行はサーバーの `event`（最新の発表）ではなく受信済みの全報から作ります。`event` は最後の発表の内容なので、震度を持たない震源要素更新（VXSE61）が後に届くと最大震度が空になるためです。震度の絞り込みも同じ値を使います
  - 長周期地震動に関する観測情報（VXSE62）を受信している地震は、バッジの下に最大長周期地震動階級（「階級 3」など）を階級の色で表示します。詳細画面の見出しのバッジも同じです
- 津波：最高の区分の色帯、区分ごとの予報区、継続中のときは注目すべき観測値
- 関連情報：情報の種類（巨大地震警戒・注意など）の色付きラベルと本文の要約

検索・絞り込み・未読・ピン留めは従来どおり使えます。

**地震の詳細**
1つの地震について受信したすべての電文を、種類ごとにまとめて表示します。
1. 見出し：最大震度（観測値がなければ予想値）、震源、発生時刻、M（値がなければ「Ｍ不明」「Ｍ８を超える巨大地震」など電文の記載）、深さ、震央の座標、精度の注記、震源の出典、受信した電文の種類。「震源の詳細」を開くと、発現時刻、震源の記述、詳細な震央地名・補足、陸域・海域、決定機関、Mの種別、精度ランク、震央地名コードを表示します
2. 緊急地震速報：警報（見出し、地方・府県予報区・細分区域ごとの対象地域、付加文）、予報（震源要素・精度ランク・予想最大震度・予想最大長周期地震動階級・最大予想震度の変化と理由）、地域別の予想（震度の範囲、警報の地域、長周期地震動階級、到達予想時刻または「既に主要動到達と推測」などの状況）、報ごとの推移表（変化の理由を併記。すべての報はシートで表示）。到達予想時刻は気象庁の発表値をそのまま表示し、秒読みはしません
3. 付加文・留意事項（津波の有無など）
4. 各地の震度：細分区域を震度別にまとめた一覧。「市町村・観測点まで見る」で、地域別または震度別の全件一覧を開きます。全件一覧には、震度5弱以上未入電、震度の修正（上方修正・追加）、地域・観測点のコードも表示します
5. 長周期地震動：最大階級、区分、地域別の階級、観測点ごとの階級と絶対速度応答、周期帯別の階級と絶対速度応答
6. その他の記載（見出し・本文・分類できない項目）、取消された電文

**津波の詳細**
- 発表中の区分と予報区
- 大津波警報・津波警報・津波注意報・津波予報・解除の区分ごとに、予報区・予想される高さ・第1波の到達予想・潮位観測点の到達予想と満潮
- 津波情報（VTSE51）の到達予想と満潮
- 沿岸の観測、沖合の観測、沿岸の推定（上昇中・更新・高い値の順に表示）
- 関連する地震、留意事項

**関連情報の詳細**
情報の種類、発表内容、補足、本文、次の発表、地震回数、関連する地震、受信資料（原文・BUFRの保存）を表示します。

**全カテゴリー共通の欄**
- 前回からの変更
- 発表履歴（新しい順）。各報を開くと、その報の全項目（通知本文、数値、地域、bulletinの全セクション、電文情報）を表示します
- 最新の報の電文情報：電文種別、配信区分、発表区分、報数（EEW）または通番、発表・配信・受信の時刻と受信までの時間、有効期限、各ID、原電文の形式・サイズ・SHA-256

VPSが構造化した項目（`eew`、`intensity_observation`、`related_earthquakes`、`hypocenter` の追加項目）があればそれを使い、ない報（旧版のVPSで解析した報）は従来どおり `affected_areas` とbulletinのセクションから表示します。地図の観測点は、観測点コードで照合し、見つからない場合だけ名称で照合します。

bulletinのセクションは、必ずどれか1つの表示欄に割り当てます。分類できないセクションは「その他の記載」に出します（`BulletinLayout` と `PresentationTests` で確認しています）。

## Apple Watch

- ホーム：発表中の津波警報、継続中のEEW（警報は赤）、最新の地震、地震・津波の件数、同期の状態
- 一覧：震度バッジ（長周期地震動の階級があれば下に併記）、震源、時刻、M・深さ
- 詳細：最大震度または予想最大震度（長周期地震動の階級を併記）、情報の種類、M・深さ・注記、留意事項、各地の震度（上位8件）、津波の区分ごとの予報区と高さ、観測、発表内容

iPhoneから送る `WatchEventSnapshot.detail` は任意の項目です（`longPeriodClass` も任意の項目として追加）。スキーマの版は変えていないため、iPhoneとWatchの版が一時的に違っても読み込めます。

## Live Activity

サーバーから送る項目は変えずに、レイアウトだけを変えました。
- ロック画面：左に予想最大震度のバッジ（津波は区分の色の印）、右にタイトル・報数・要約（2行）・状態・発表時刻
- Dynamic Island：コンパクト表示とミニマル表示には震度の色付きラベルを出します。展開表示にはバッジ・タイトル・報数・時刻・要約・状態を出します

160ptの高さ制限は既存のテストで確認しています。
