# 地震・津波関連の受信と表示

契約済みの eew.forecast、eew.warning、telegram.earthquake の3区分を購読します。typesフィルターは省略、formatsはjson / a/n / binary、testはnoです。

| 電文 | 内容 | タブ |
|---|---|---|
| VXSE44 / VXSE45 | 緊急地震速報（予報） | 地震 |
| VXSE43 | 緊急地震速報（警報） | 地震 |
| VXSE51 / VXSE52 / VXSE53 | 震度速報・震源・震源震度 | 地震 |
| VXSE61 | 顕著な地震の震源要素更新 | 地震 |
| VXSE62 | 長周期地震動観測 | 地震 |
| VTSE41 | 津波警報・注意報・予報 | 津波 |
| VTSE51 | 津波到達予想・満潮・観測 | 津波 |
| VTSE52 | 沖合観測・沿岸推定 | 津波 |
| WEPA60 | 国際津波関連（国内向け） | 津波（原文資料） |
| VYSE50 / VYSE51 / VYSE52 | 南海トラフ臨時・関連解説 | 関連情報 |
| VYSE60 | 北海道・三陸沖後発地震注意 | 関連情報 |
| VXSE56 / VXSE60 | 地震活動・地震回数 | 関連情報 |
| IXAC41 | 推計震度分布図作成用BUFR | 関連情報（数値資料） |
| VZSE40 | 地震・津波お知らせ | 関連情報 |

対象は20種。XML由来のJSONはstatus=通常だけを扱い、訓練・試験とVXSE42（配信試験）は実際の情報として表示・通知しません。未知電文は推測して解釈せず無視します。契約や提供電文の変更時は一覧と正規化を再確認します。

## 発表履歴と詳細

「第○報」「最終報」はEEWだけに表示します。通常情報は発表時刻と発表区分（発表・訂正・遅延・取消）で表示し、旧キャッシュの報番号も表示しません。原電文のserialNoは保持します。

津波と関連情報のIDは地震と別の名前空間です。通常情報は発表時刻、同時刻なら配信発表時刻、訂正・取消の順序を使い、取消後の新しい発表も受け入れます。津波の解除は予報区の区分として保持し、情報そのものの取消と区別します。タブは受信履歴であり、現在の警報一覧を保証するものではありません。

津波の予報・観測・沿岸推定を区別し、「巨大」「高い」「以上」「上昇中」「欠測」などを保持します。欠けた数値を0で補いません。南海トラフは種類・本文・補足・次回発表、長周期地震動階級は震度と別項目で表示します。

認証された端末から非EEWの原電文を保存できます。画面に展開していない元項目もJSONに残ります。EEW原文ダウンロードは拒否し、警報の非表示対象数値を取得する経路を増やしません。

IXAC41は画像ではなくBUFR数値データです。地図描画は未対応。分割配信は同じ発表の履歴に各受信片を保存します。順不同でも後続片を初期片で巻き戻さず、単独で長さと終端を確認できたBUFR以外を完全と表示しません。結合・欠落片の自動取得は行いません。

WEPA60は原文表示・保存に対応します。A/Nとバイナリはtest=noでも試験が配信され、head.testで通常情報と判別できないため、受信資料として保持し自動プッシュ通知しません。

## 通知と更新

初回アプリ更新時に既存の通知全体・音・Time Sensitive・地震・EEWの設定を維持して、追加区分を一度有効にして保存します。以後は追加区分もサーバーから復元します。通知全体OFFは維持し、設定画面から津波・関連情報を変更できます。

津波警報・注意報と南海トラフの巨大地震警戒・注意は、許可されていればTime Sensitiveを使います。Critical Alertsは使いません。通知から該当タブへ移動します。

サーバーを先に更新してからTestFlightを更新します。秘密設定・端末登録・ペアリング・保存履歴を引き継ぎます。切断期間の自動補完、過去の未受信電文の遡及取得、OAuth自動更新、履歴自動削除は未対応です。

## 検証

Goは契約対象20種、訓練除外、訂正・取消・解除、高さの修飾、南海トラフ、長周期、BUFR分割、原文取得の認証とEEW拒否を検査します。Swiftは報番号・通知設定・タブ振り分けを検査します。Swift→Go受入試験は隔離環境の合成10電文と原文取得を使い、画面試験では通常情報・津波・南海トラフを表示します。

合成試験は各種の実電文やAPNsのiPhone到達を確認したものではありません。
