# 通知とLive Activity

## EEWが二度届く原因と修正

DMDATAのVXSE44は旧EEW予報、VXSE45はその後継です。同じ地震・報数について両方が届くため、旧版では両方が通知されていました。VXSE44は履歴だけに保存し、自動通知にはVXSE45を使います。更新前に作られたVXSE44の未送信通知もスキップします。VXSE45が存在する地震の詳細では旧予報を非表示にします。VXSE43の警報・警報への昇格・取消は独立した電文として扱います。

[DMDATA EEW](https://dmdata.jp/docs/eew/)では旧VXSE44の廃止予定とVXSE45の利用が案内されています。

## 受信状態

認証済みのGET /api/v1/statusから、DMDATAの接続と100秒未満のフレーム受信を確認します。地震電文の到着時刻は接続の判定に使いません。アプリが前面にある間は30秒ごとに確認し、最後の確認から75秒を過ぎると「未確認」にします。履歴の同期時刻は別に表示します。受信未設定のoffline、接続断、サーバーに接続できない状態を区別します。

## 通知設定

すべての受信対象は保存を続けます。絞り込みは送信前に、端末ごとの保存済み設定で判定します。初期設定では地域・最低震度を絞らず、Live Activityはオフです。

- EEW予報・警報、津波警報や注意報・予報や観測、南海トラフ・その他の関連情報を個別に選べます。
- 地震は都道府県・細分地域名、津波は津波予報区名を読点・カンマ・改行で区切って入力します。空欄は全地域です。電文の名称と一致または前方一致する地域を対象にします。
- 指定地域の震度が分かる場合は、その地域の最大値を最低震度と比較します。他地域の大きな震度を使って判定しません。
- 地域・震度が不明な電文は通知を残します。EEW予報には震度4未満の地域が省略されるため、最低震度が未指定または4未満で対象地域が見つからない場合も残します。EEW警報には最低震度を適用しません。
- 同じ地震・同じ電文系列で通知した情報の取消・最終報・津波警報や注意報がなくなった発表は、地域・種別の変更後も知らせます。全通知オフは常に優先します。取消を安全宣言や津波の解除として解釈しません。

[DMDATA EEW schema](https://dmdata.jp/docs/reference/conversion/json/schema/eew-information/)が地域の省略と予測値の範囲の根拠です。

## 自分の端末への通知テスト

POST /api/v1/devices/me/notification-testsは認証した端末だけへ送ります。送信先の上書きはできません。通常音または警報音を選び、保存済みの音・Time Sensitive設定に従います。テストである旨をタイトルと本文へ表示し、地震履歴に追加しません。

新規要求は1分に1回までです。要求IDを永続保存して同じ要求の再送を防ぎます。APNs受理、拒否、結果不明を区別し、APNsの受理だけでiPhone到達を確認済みにはしません。

## Live Activity

iOS 17.2以降で、通知とLive Activityを両方有効にして保存すると自動開始用トークンを登録します。EEW予報（VXSE45）と津波警報・注意報（VTSE41）を対象にします。EEW警報（VXSE43）の通常通知は独立して届きます。

Appleのpush-to-startにはアラートが必要なため、最初の電文ではLive Activityの開始を通常通知と兼用します。二つのアラートを送信しません。開始が拒否された場合は通常通知に戻します。以降の電文では各報の通常通知を維持し、Live Activityの更新・終了はアラート・音を付けずに行います。トークン登録の間に来た続報は最新の状態へ追い付きます。EEWと津波、電文系列間の報数を相互比較しません。

取消・最終報・津波警報や注意報がなくなった発表で表示を終了します。取消には解除ではないことを明示します。終了した表示は5分後に取り下げる指定を送り、実際の表示はiOSに従います。設定をオフにするかペアリングを解除すると終了を要求します。端末で閉じた活動は再作成しません。トークン更新時に古いトークンの失敗が新しいトークンや通常APNs登録を無効にすることはありません。

EEWは1分、津波は15分で更新が古くなったことを明示します。発表時刻と仮定・低精度の注記を残します。震動到達のカウントダウンは表示しません。実際の到達時刻を計算していないためです。

表示・更新はiOSの権限・通信・APNsの制限に従います。CIのビルド・シミュレーター結果は本番APNsや実機のLive Activity確認とは別です。

[Apple ActivityKit push notifications](https://developer.apple.com/documentation/ActivityKit/starting-and-updating-live-activities-with-activitykit-push-notifications)と[Live Activityの表示](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities)に従います。配布時は[内部TestFlight手順](testflight-distribution.md)の拡張専用署名も用意します。
