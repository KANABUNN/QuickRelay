# 通知の対象範囲

この文書は初回リリースの記録です。現在の範囲は[受信対象と表示](earthquake-tsunami-products.md)に更新されています。

対象は次の5電文です。詳しい表示内容・順序・取消の扱いは[イベント仕様](event-semantics.md)を参照してください。

| 電文 | 情報 | 通知・表示 |
|---|---|---|
| VXSE45 | 緊急地震速報・地震動予報 | 各報、予想最大震度、判明している震源情報。仮定値には注記。 |
| VXSE43 | 緊急地震速報・警報 | 警戒の呼びかけ、対象地域、震央地名、予想最大震度。警報由来のM・深さは表示せず、同じ地震の予報値を出所付きで別枠表示。 |
| VXSE51 | 震度速報 | 最大震度等 |
| VXSE52 | 震源に関する情報 | 震源・マグニチュード等 |
| VXSE53 | 震源・震度に関する情報 | 震源・最大震度・マグニチュード等 |

5種は電文の種類数であり報数の上限ではありません。予報と警報は別系列で、続報・最終報・訂正・取消を扱います。対象電文内の全フィールドを表示する意味ではありません。

保存した報のうち、端末の通知設定・最新判定・有効期限等を満たすものをPush対象にします。地域・震度による独自の絞り込みは追加していません。訓練・試験電文を通常通知へ流さず、接続テストは明示的な別用途として扱います。

Time Sensitiveと通知音は端末・ユーザー設定に従います。Critical Alertは対象外です。

津波、南海トラフ、長周期地震動などの専用電文は次段階の対象です。DMDATA契約区分に含まれる全電文を扱う製品ではありません。切断区間の自動backfill、OAuth自動更新、履歴自動削除も未実装です。端末の同期で回収できるのはVPSが受信・保存した履歴だけです。

実DMDATA、APNs受理、iPhone表示、履歴同期の受入は、ローカル・CIとは分けて実施します。

参照: [DMDATA EEW仕様](https://dmdata.jp/docs/reference/conversion/json/schema/eew-information/)、[DMDATA地震情報仕様](https://dmdata.jp/docs/reference/conversion/json/schema/earthquake-information/)。
