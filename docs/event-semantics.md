# イベント・通知仕様

既存のGo版の振る舞いを維持します。Windowsの通知文字列解析・Agent HMAC・Named Pipeを新APIへ持ち込まず、次の共通仕様を継承します。

- 地震の識別子はDMDATAの `eventId`。津波・関連情報は別の名前空間を使い、地震IDと衝突させません。報のIDは受信message IDのSHA-256です。message IDと正規化内容の両方で重複を排除します。
- EEWの最新報の比較は `eventId + telegram_type` 単位。VXSE44・VXSE45の予報同士や警報のserialを相互比較しません。同じserialの取消・最終を反映し、古い報で終端状態を復活させません。
- `report.revision` / `event.source_serial` は配信元のserialNo（EEWだけを報数として表示）、`server_sequence` / `latest_revision` はサーバーでの順序です。報数と同期cursorを混同しません。
- `occurred_at` は電文発表、`origin_time` は地震発生、`received_at` は受信時刻です。未知の震源数値はnullとし、推測で埋めません。
- タイトル・本文は `server/internal/dmdata/normalize.go`、APNs payloadは `server/internal/relay/worker.go` で生成します。警報にも震央地名・予想最大震度を記載します。警報由来のマグニチュード・深さはAPIの追加項目を含め非表示です。
- 各報を独立した通知とし、event IDでthreadをまとめます。取消・最終・警報、通知設定、Time Sensitive、CAF音、失効token、古い速報の抑止を継続します。
- EEWのローカル有効期限は60秒、通常地震情報は10分。EEWのAPNs expirationは0。履歴replayはAPNsキューを作りません。
- 履歴と送信キューを同一トランザクションに保存します。APNs受理直後の停止による再送重複や配信欠落は完全には防げません。

対応電文・運用上の制限は[サーバー手順](../server/README.md)を参照してください。

## 本人利用向けの数値表示

利用対象は本人のみとし、第三者へのアプリ配布・データ公開を行わない。これはDMDATAの警報表示条件を免除するものとは扱わない。[DMDATA EEW取扱条件](https://dmdata.jp/docs/eew/)に従い、警報のM・深さは表示しない。

- `Report.hypocenter` と `Event.hypocenter` は任意の追加項目。震央地名、発生時刻、緯度・経度、M、深さと、`status`（`estimated` / `assumed` / `low_accuracy`）、`note`、深さの例外表現 `depth_condition` を保持する。未知の値をM1.0や10km等で補完しない。
- 仮定震源は値を保持して「仮定値」と併記する。PLUM法の仮定震源と、精度コードによるレベル法等を判定し、1点観測等には低精度の注記を付ける。通知では注記を数値・対象地域の前に置く。
- 仮定値は従来のトップレベル数値項目には入れず、注記を伴う `hypocenter` のみに入れる。旧アプリが仮定値を通常の震源として表示することを避ける。警報のM・深さはこの追加オブジェクトでもnullとする。
- iOSは予測を「予想最大震度」、観測を「観測最大震度」と表示する。深さの「ごく浅い」「700km以上」も保持する。一覧・詳細・報履歴で仮定値の注記を確認できる。
- 警報の詳細には、同じevent IDのVXSE45の最新有効報（VXSE45未受信ならVXSE44）を「同じ地震の予報値（参考）」として別に表示する。出所・予報の報数・発表時刻・注記を併記し、その予報のM・深さを表示する。警報のフィールドへ混ぜず、予報未受信・取消時は値を補完しない。VXSE45取消後にVXSE44へ戻さず、2種類の報数を混ぜて比較しない。遅れて届いた旧報や最終報後の通常報で参考値を巻き戻さない。
- 新しい保存項目は任意で、旧API応答・旧iOS保存データも読める。保存済みの過去電文をこの変更で再正規化・再通知しない。過去の省略済み情報は復元されず、新しく受信する報から詳細値を保持する。

更新にはVPSの新しいバイナリとiOSの新しいTestFlightビルドの両方が必要。Gitの統合・CI成功だけでは稼働環境へ反映されない。

## 再利用データ

[読み上げ辞書とfixture](../contracts/fixtures/text-normalization/README.md)は旧実装から内容を変えずに抽出しました。将来の発話機能の検証材料であり、現在の通知表示本文には自動適用しません。数値を変更しないこと、未知の文字列を推測で言い換えないことを維持してください。


通常情報は報番号ではなく発表区分と時刻を表示します。津波解除と電文の取消は別です。追加電文の表示・通知・原文保存・更新規則は[受信対象と表示](earthquake-tsunami-products.md)を参照してください。
